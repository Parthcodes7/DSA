# DSA

This repository contains my Data Structures and Algorithms practice code.

## Structure

- **01_Learn_the_basics/**: Basic programming concepts, maths, hashing, logic and patterns, recursion, and C++ STL.
- **02_Sorting/**: Various sorting algorithms implemented in C++.
  - Bubble Sort (Iterative and Recursive)
  - Selection Sort
  - Insertion Sort (Iterative and Recursive)
  - Merge Sort
  - Quick Sort
- **03_Array/**: Array solutions from Striver's A2Z DSA Course.
  - Largest Element in an Array
  - Second Largest & Second Smallest Element
  - Check if Array is Sorted
  - Remove Duplicates from Sorted Array
